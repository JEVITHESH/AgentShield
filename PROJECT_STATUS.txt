1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
AgentShield is a dynamic security and autonomy-control middleware SDK for
Model Context Protocol (MCP) based autonomous AI agents. It intercepts tool
requests, computes dynamic 8-factor operational risk, enforces security lattice
boundaries, tracks cumulative tool-chain risk, and manages human-in-the-loop
approvals with cryptographic execution integrity.

Development follows a strict 12-phase workflow. Currently, Phase 1, Phase 2,
and Phase 3 are 100% completed, reviewed, and approved. Phase 4 (Dynamic Risk
Assessment Engine) is actively in progress with core evaluators and engine
implemented.
